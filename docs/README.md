# Документация tcloud-frontend

Точка входа — [README.md](../README.md) (запуск, сборка, Docker, обзор возможностей). Здесь — как всё устроено, со
схемами Mermaid, сверенными с кодом.

| Файл | О чём |
|---|---|
| [architecture.md](architecture.md) | запуск, провайдеры, маршруты, оболочка `Layout`, прокси `/api`, авторизация и refresh, события окна, i18n |
| [data-flow.md](data-flow.md) | ключи TanStack Query, карта инвалидаций, сторы вне Query, настройки: загрузка, слияние, оптимистичное сохранение, перенос |
| [uploads-and-tasks.md](uploads-and-tasks.md) | точки входа загрузок, XHR-отправка, отслеживание задач, `TaskWatcher`, статусы |
| [theming.md](theming.md) | темы и пресеты, `data-theme`/`.light`, токены, как добавить тему |

Правило: изменение кода, которое меняет поток со схемы, обновляет документ и схему в том же коммите.
API бэкенда описан в `../tcloud-backend/docs/`.
