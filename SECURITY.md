# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/NikitkaZXC/tcloud-frontend/security/advisories/new)
("Report a vulnerability" on the Security tab). Include the affected version, steps to reproduce and the impact.

You should get a reply within 7 days. Once a fix is released, the advisory is published with credit unless you ask
otherwise.

Issues in the API itself belong to [tcloud-backend](https://github.com/NikitkaZXC/tcloud-backend/security/advisories/new).
